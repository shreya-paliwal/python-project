The repository contains scripts for the three games built with Python that runs directly in the terminal.
The three games are as follows:
1. Guess The Number game
2. Rock Paper Scissors game
3. Hangman game

In detail

**1. Guess The Number game**

   File required: project1_guesstheno.py

   A simple game that generates a random number from the given list, and asks for the user input to guess the number correctly.


**2. Rock Paper Scissors game**
   
   File required: project2_rps.py
   
   Like the traditional rock paper scissors game, here user play against computer, both chooses a random attack for the round.


   **Features included:**
   
   -Random number generation
  
   -User input interaction
  
   -Score tracking
  
   -Play Again feature
  
   -Terminal based game aesthetics
   
   **Concepts demonstrated:**

   -> Python functions and classes
   
   -> Conditional statements
   
   -> While loops
   
   -> User input
   
   -> Use of python library (random)

   

**3. Hangman game**

   Files required:
   
   -hangman.py
   
   -hangman_character.py
   
   -words.py


   It is a word completing game, where every correct letter gets you closer to win, and every wrong letter results in loss of lives.
   With every loss of lives, the hangman character takes shape.
   
   Hangman character is stored in the hangman_character.py script in the dictionary feature with key as the lives left and value as hangman structure.
   
   Words.py consists of a long list of words.

   **Features included:**
   
  -Random word generation
  
  -User input interaction
  
  -Lives tracking
  
  -Hangman character visual generation
  
  -Game aesthetics
  
  -Play again feature

   **Concepts demonstrated:**
   
  -> Use of python libraries (random)
  
  -> Importing data from other scripts
  
  -> Function defining
  
  -> Python function and classes
  
  -> Conditional statements
  
  -> While loops
  
  -> List comprehension
